# Buildfree-landing-page

Landing site for buildfree, built with Vite and React.

```bash
npm install
npm run dev     # local dev server
npm run build   # production build in dist/
```

Pages: `/` (home), `/docs/`, `/pricing/`.

The home page currently shows a temporary service page. To bring back the full landing page, set `TEMP_SITE` to `false` in `src/App.jsx`.
